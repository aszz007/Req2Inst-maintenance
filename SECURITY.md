# Security Policy

## Supported versions

Req2Inst has not yet made a public software release. Security fixes are applied
to the current private `main` development line. A public supported-version
table will be added when versioned releases begin.

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue. Use a private GitHub
security advisory for this repository or contact the repository owner through a
previously established private channel.

Include:

- The affected file, component, and commit.
- Reproduction steps and required environment.
- Expected and observed impact.
- Whether credentials, private data, model files, or generated artifacts may
  have been exposed.
- A suggested mitigation, if available.

Maintainers will acknowledge a complete report when it is reviewed. Response
and disclosure timelines depend on research schedules and the severity of the
issue.

## Sensitive material

Never commit access tokens, browser profiles, private datasets, unpublished
paper content, personal data, or model credentials. If such material is found,
stop redistribution and coordinate history cleanup privately before disclosure.
